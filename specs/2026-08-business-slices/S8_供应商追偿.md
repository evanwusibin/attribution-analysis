# S8 · 供应商质量与反向索赔归因切片 Spec

> **状态**：implemented（2026-08-17 本地实现）
> **依赖**：S3 售后共享证据底座 + S4 电池包故障域

## 1. 范围

### 目标
- 读取供应商不良率、采购质保合同、批次故障率
- 输出追偿候选（质保期内 + 不良率超均值 + 批次异常）
- 终止规则：缺少合同或批次追溯时禁止自动追偿

### 非目标
- 不自动发起追偿
- 不自动扣款

## 2. 数据与规则

| 数据对象 | 来源等级 | 规则 |
|---|---|---|
| suppliers | MOCK | 不良率 vs 行业均值 2% |
| supplier_warranty_contracts | MOCK | 质保期判定（active/expired） |
| part_batches | MOCK | 批次故障率 |
| supplier_recourse_claims | MOCK | 历史追偿记录 |

- 行业均值 2% 标记 `MOCK` 阈值
- 关键：缺少合同/批次 → `MISSING` → 只输出候选假设

## 3. 接口

`POST /api/v1/supplier-recourse/analyze`
```json
{"question": "供应商SUP-005批次不良率异常能否追偿", "supplier_id": "SUP-005", "batch_id": "B-2024-Q1"}
```

## 4. 测试契约

- SUP-005 不良率 8% 超均值 → 追偿候选
- 质保过期 → 不可追偿（SWC-004）
- 缺合同 → MISSING 降级，不自动追偿
- 反例：缺少批次追溯时输出待补充

## 5. 验收

- 输出六段结构
- 候选追偿 + 人工复核门禁
