## 4. 状态与接口

### 4.1 会话状态机

```
active → archived → deleted
   └─────────→ deleted（直接删除）
```

- 非法迁移（如 deleted → active）记录拒绝原因。
- 删除会话时级联：消息、附件记录、任务记录、结果记录、上下文摘要记录 + `uploads/{user_id}/{conversation_id}/`、`exports/...`、`workspace/...` 三目录。

### 4.2 任务状态机

```
queued → running → success
   │        │
   │        ├→ failed（含 error_message）
   │        └→ cancelled（停止后续步骤，已获取证据保留）
```

- 取消在只读工具边界生效；已获取证据保留并可读取。
- 服务重启/断连后通过 `GET /api/tasks/{task_id}` 恢复；`running` 超时未心跳可重置为 `failed` 或允许重试。

### 4.3 附件状态机

```
parsing → ready
    └──→ failed（返回错误原因）
```

### 4.4 接口清单（对齐 PRD 九）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/auth/login` | 跳转认证中心发起授权登录 |
| GET | `/auth/callback` | 处理回调参数、换取访问令牌、保存登录态并跳转工作台 |
| POST | `/api/chat/create` | 请求 `title`；响应 `conversation_id`、`title`、`status` |
| POST | `/api/chat/delete` | 请求 `conversation_ids`；级联删除 |
| POST | `/api/chat/update` | 请求 `conversation_id`、`title`；重命名 |
| GET | `/api/chat/ls` | 会话列表 |
| GET | `/api/chat/ls/{conversation_id}` | 历史消息 |
| POST | `/api/attachment/upload` | 请求 `conversation_id` + 文件；响应附件记录 |
| POST | `/api/attachment/delete` | 请求 `attachment_id` |
| GET | `/api/attachment/get` | 请求 `attachment_id`；返回文件 |
| POST | `/api/chat/ws-token` | 签发 WebSocket 临时令牌：`websocket_token`、`expires_in` |
| WS | `/api/chat/ws/chat` | 连接参数 `websocket_token`、`conversation_id`；推送实时消息 |
| GET | `/api/tasks/{task_id}` | 任务状态 |
| GET | `/api/results/{task_id}` | 结构化结果 |
| POST | `/api/admin/reload` | 配置热更新：响应 `status`、`message` |

### 4.5 WebSocket 消息时序契约

```
客户端连接 /api/chat/ws/chat?websocket_token=...&conversation_id=...
服务端推送顺序（每轮分析）：
  message_start → (message_delta)* → (tool_start → tool_finish)* → task_status* → result_ready → done
  任意时刻可插 error（本轮分析失败）
```

| 类型 | 字段（至少） | 触发时机 |
|------|-------------|---------|
| `message_start` | `task_id`、`conversation_id` | 本轮分析开始 |
| `message_delta` | `task_id`、`delta_text` | 模型增量文本 |
| `tool_start` | `task_id`、`tool_name` | 工具开始执行 |
| `tool_finish` | `task_id`、`tool_name`、`tool_result_summary` | 工具执行完成 |
| `task_status` | `task_id`、`task_status`、`current_step` | 任务状态变化 |
| `result_ready` | `task_id`、`result_id` | 结构化结果已生成 |
| `error` | `task_id`、`error_message` | 本轮分析失败 |
| `done` | `task_id`、`finished_at` | 本轮分析结束 |

## 5. 失败与降级

- **认证失败**：非法/过期 websocket_token 拒绝连接；登录失败跳转错误页。
- **WS 断连**：任务状态通过 `GET /api/tasks/{task_id}` 恢复；`running` 超时未心跳可重置为 `failed` 或允许重试。
- **附件上传失败**：返回 `failed` 状态 + 错误原因，不残留半文件。
- **配置热更新非法**：保留上一份有效配置，返回错误，不得进入半更新状态；成功更新写运行日志。
- **路径穿越**：`../` 越权读写一律拒绝（校验 `user_id`/`conversation_id` 与目标路径一致性）。
- **日志脱敏**：含敏感信息时脱敏；管理员日志查看不得泄露其他用户会话明文。

## 6. 测试要点（B2 红测方向）

> 认证相关契约（`认证登录门禁`、`非法 token`）随认证阶段延后，不阻塞其余能力红测。

| 契约 | 给定 | 期望 | 失败即阻断 |
|---|---|---|---|
| WS 消息时序 | 正常分析任务 | message_start→...→done 按契约顺序推送 | 缺消息或乱序 |
| 断连恢复 | 任务 running 时断连 | `GET /api/tasks/{task_id}` 可恢复状态 | 状态丢失 |
| 级联删除 | 删除含附件/任务/结果的会话 | 记录与三目录全部清理 | 残留记录或文件 |
| 路径穿越 | 上传文件名含 `../` | 拒绝并记录 | 文件写到目录外 |
| 配置回滚 | `reload` 传入非法配置 | 返回错误且上一份配置仍生效 | 半更新状态 |
| 日志脱敏 | 日志含敏感信息 | 输出脱敏版本 | 明文泄露 |
| 日志落库 | 任务执行/失败 | 写入 `task_logs`，可按任务过滤 | 无日志记录 |
| 幂等创建 | 相同幂等键重复创建会话/任务 | 单一记录 | 重复创建 |
| 历史追问 | 切换旧会话继续提问 | 新 Plan/Result 版本与原记录共存 | 覆盖原版本 |
| 认证登录门禁（延后） | 未登录访问工作台 | 重定向 `/auth/login`；回调换取 token 后可进 | 未认证可访问受保护路由 |
| 非法 token（延后） | 过期/伪造 websocket_token | 拒绝连接，返回错误 | 接受非法 token |

## 8. 知识摄取与报告交付补充契约

### 8.1 导入与检索分层

导入按钮只进入知识摄取链路，不向 NL2SQL 的业务数据库写数据。附件必须先绑定 Case，再保存原文件、SHA-256、解析快照和知识版本；元数据进入平台 MySQL，检索分块与 embedding 进入向量数据库。RAG 返回的每个片段必须引用 `attachment_id`、内容哈希、分块定位与知识版本。

NL2SQL 只读查询业务库，RAG 只读查询向量索引。任一通道失败时，另一路继续完成，失败通道以 `ToolExecution` 和 `Evidence=MISSING` 公开显示，结果强制人工复核。

### 8.2 报告契约

报告采用 HTML-first、A4 CSS 模板。仅允许从当前主体拥有的 Case、Result 和 Evidence 派生；支持预览与受限下载，下载记录必须包含 Case、主体、模板和时间。不得接受客户端任意拼装的事实、结论或证据作为正式报告来源。

### 8.3 工作台转换

提交问题后，欢迎页必须隐藏并切换到整体归因链路：`问题 → Plan → NL2SQL / RAG → Evidence → Result → 人工复核`。工作台、案件、会话历史、证据中心、分析轨迹、知识库和导出中心均为同一 Case 上的不同读取视图；新建会话创建新的 Conversation/Case 边界，不能覆盖历史版本。
