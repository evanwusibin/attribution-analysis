# S7 · 服务店运营与星级评定归因切片 Spec

> **状态**：implemented（2026-08-17 本地实现）
> **依赖**：S3 售后共享证据底座

## 1. 范围

### 目标
- 读取服务店星级与检查项得分
- 一票否决项判定（is_veto 未达标 → 降级建议）
- 总分计算与升降级评估

### 非目标
- 不自动降级、扣减折让系数
- 不生成处罚动作

## 2. 数据与规则

| 数据对象 | 来源等级 | 规则 |
|---|---|---|
| service_stations | MOCK | 当前星级/折让系数 |
| star_evaluation_items | MOCK | is_veto=1 且得分<满分 → 一票否决 |

- 评分线、星级阈值全部标记 `MOCK`（待映射原始评定制度）

## 3. 接口

`POST /api/v1/star-evaluation/analyze`
```json
{"question": "深圳4S店星级评定", "station_code": "SS-001"}
```

## 4. 测试契约

- 一票否决判定（SS-001 远程视音频系统未上线 → 降级建议）
- 总分计算
- 不自动降级（只输出建议 + 人工复核）

## 5. 验收

- 输出六段结构
- 阈值显式标记 `MOCK`
