# CRM 风格登录与工作台视觉规格

> **状态**：draft。仅复用 CRM 项目的视觉与布局模式，归因系统保有独立领域、文案、品牌和前端契约。

## 1. 可复用与禁止复用

| 来源 | 可借鉴 | 禁止复制 |
|---|---|---|
| `CRMProject_c/web/login.html` | 双栏登录信息层级、企业卡片、加载/失败反馈 | “精诚助手”、BYD 标识、登录逻辑、凭据处理 |
| `CRMProject_c/web/index.html` | 左侧导航 + 顶部上下文 + 主工作区布局密度 | CRM 菜单、iframe 业务页、DOM、存储键、API 调用 |
| `CRMProject_c/web/assets/master.css` | 间距、圆角、阴影、文字层级、色彩令牌的设计方法 | 原始品牌资源、类名耦合和直接拷贝业务样式 |

## 2. 归因工作台布局

```text
登录页：品牌说明 / 权限与数据边界 → 身份提供方授权 → 回调结果

工作台：
┌ 左侧导航 ──┬ 会话与对话主线 ────────────────────┬ 结果抽屉 ──┐
│ 工作台      │ 顶部：Case / 场景 / 数据环境 / 状态 │ 结果摘要    │
│ 会话历史    │ 消息、Plan、可审计执行轨迹           │ 指标与证据  │
│ 复核队列    │ 附件、输入、取消/提交               │ 限制/复核   │
│ 导出中心    │                                      │ 导出/追问   │
│ 管理台*     │                                      │             │
└────────────┴────────────────────────────────────┴─────────────┘
```

`*` 仅系统管理员可见。左侧不展示技术 ID；右侧不展示模型原始思维链、任意 SQL 或凭据。

## 3. 视觉令牌与状态

- 使用独立的 `--brand-*`、`--surface-*`、`--text-*`、`--status-*` 令牌，不引用 CRM 的品牌命名或 logo。
- 采用 8px 间距、12px 圆角、分层卡片和高对比正文；桌面为三栏，窄屏将结果抽屉改为可访问侧栏。
- `FACT`、`MOCK`、`MISSING` 必须同时使用文字、形状/图标和辅助说明；颜色只作辅助。
- P-01 到 P-09 的可见动作以 D6 为准：失败显示可恢复范围，复核显示 ReviewAction 时间线，任何状态均不显示外部处置按钮。

## 4. 实现验收

- 登录、授权失败、会话过期、空态、加载、无权限和断线恢复均有明确页面反馈。
- 工作台刷新后仅从 D5 查询/事件恢复持久化状态，不依赖浏览器本地伪造进度。
- 视觉复刻不得改变 G1 状态、D5 权限或 D4 数据模型。
