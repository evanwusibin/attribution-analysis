## 3. 追踪矩阵

| 需求/风险 | 领域对象与状态 | 数据/规则来源 | 原型状态 | 接口类别 | 切片 | 测试与验收证据 |

| 无证据不得裁决 | `Evidence`、`AttributionResult`、`needs_input` | `MISSING` | P-05 待补充 | 读取结果 / 追问 | S1 | 缺失关键字段时无责任结论 |

| S1 电池诊断 | `fault_cases`、诊断路径、候选根因 | 信号 `FACT`；阈值按 `MOCK` | P-04 / P-05 / P-07 | 任务 / 结果 | S4 | 正常、异常、证据不足、反例均可复现 |

## 4. 状态语义

| 状态 | 含义 | 允许推进到 |
|---|---|---|
| `draft` | 已有内容，但未完成跨文档核验 | `review` |
| `review` | 已具备准出材料，等待产品/架构评审 | `approved` 或回到 `draft` |
| `approved` | 允许为指定切片编写测试与最小实现 | `implemented` |
| `implemented` | 已有实现，尚无运行验收 | `accepted` |
| `accepted` | 有可复现运行证据 | 后续版本维护 |
| `blocked` | 前置数据、规则、设计或评审未完成 | 前置问题解除后回到 `draft` |

## 8. 2026-08 工作台能力决策

| 决策 | 归属 | 不变量 |
