# 项目 Skill 地图

| 阶段 | 能力 | 使用边界 |
|---|---|---|
| 需求与术语 | grill-me / grill-with-docs | 一次一个不可从资料推断的问题 |
| 领域状态 | domain-modeling | 先冻结状态、转换与失败恢复 |
| 模块边界 | codebase-design | 外部复用只能定义为适配器契约 |
| 切片实现 | tdd | 先写业务契约测试 |
| 故障排查 | diagnosing-bugs | 先复现再修复 |
| 审查 | code-review | 同时检查规范与 Spec 一致性 |

本工程不复制或自动安装外部 Skill。Skill 是执行方法，不是运行时依赖。

## 通用技能库（全生命周期，位置：`13.6 项目部\通用技能库\`）

| 阶段 | 文档 | 使用时机 |
|---|---|---|
| 开发过程中 | `01_开发过程中_通用Skill.md` | 进入 TDD 切片开发、续接开发、收到开发任务时：切片纪律、红绿循环、双轴审查、门禁、变更管理、渐进式提交 |
| 代码完善 | `02_代码完善_通用Skill.md` | 调试 / 重构 / 性能优化 / 审查整改 / 技术债清理时：可证伪假设调试、重构安全规则、质量检查清单 |
| 部署上线 | `03_部署上线_通用Skill.md` | 集成/生产发布准备时：应用服务部署、GPU 模型部署（vLLM/BGE 双机）、监控回滚 |
| 评估优化 | `04_评估优化_通用Skill.md` | 系统上线后质量评估、优化检索/提示词/切片后回归验证时：RAGAS 六步流程、指标诊断、bad case 闭环 |
